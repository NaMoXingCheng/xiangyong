# 相拥 · 关系分析室

> 灵感来源于 github「她不一样」项目

一个**完全本地运行**的聊天关系分析桌面应用。它把你们之间的聊天记录变成看得见的东西：谁说得更多、聊了多久、热词是什么、冷场了多少天……最后再给你几句不客气的「AI 锐评」。

**本工具不解密、不逆向、不碰数据库。** 它只做一件最简单、最干净的事：利用「复制与粘贴」。

---

## 原理（一句话）

你在聊天软件里选中消息 → 复制（Ctrl+C）→ 工具自动接住剪贴板里的文字并解析成结构化消息。

具体来说：

| 数据 | 来源 | 说明 |
|---|---|---|
| **文字** | 剪贴板 | 你在聊天窗口「多选 → 复制」，工具监听剪贴板变化，自动解析「昵称 / 时间 / 内容」格式，逐条入库 |
| **图片** | 明文缩略图缓存 | 聊天软件自己会在本地留下**已经解码好**的缩略图（`.jpg`），工具只读这些现成文件，**不做任何解密**；只有「你点开看过」的图片才会被缓存 |
| **语音** | ❌ 不支持 | 不解密就拿不到语音内容，所以不做 |

所有数据**只在本机处理，绝不上传**。

---

## 特性

- 📋 **剪贴板自动导入**：复制几下，聊天记录就进来了，文字 100% 准确
- 📊 **关系分析**：消息数、时间跨度、谁话多、秒回情况、冷场天数、热词榜、趋势图
- 🧠 **内置本地 AI**：三档本地小模型随应用一起装，**开箱即用，不需要另装 Ollama 或任何外部服务**；按显存档位自动推荐，空闲 120 秒自动把模型从显存搬回内存
- 🗣 **AI 锐评**：毒舌但友好，按你们真实的聊天数据生成；AI 说出口的每个数字都会和真实统计核对，编造的数字会被拦下
- 💯 **可解释的关系指数**：主动 / 被爱 / 冷淡三个指数由多个信号合成，点开就能看到「这 71 分是怎么来的」
- 📖 **年度报告**：页数按你们的聊天量动态生成（最多 15 页），页间有动画与元素联动，结尾由 AI 写一段只属于你们的寄语
- ✏️ **消息可编辑**：每条消息都能改，改过会标「已编辑」
- 🖼 **自定义头像**：右键联系人即可换头像，支持选图或直接粘贴
- 🎨 **自由主题**：预设配色 + 任意取色，还有个「绿色长草」小彩蛋
- 🔊 **界面音效**：所有音效与背景音乐都是 Web Audio 现场合成，零音频文件（因此也零版权问题），可在设置里单独调节响度
- ✅ **To-Do 待办**：从聊天记录一键把「答应过 TA 的事」记下来，并跟踪兑现情况
- 📱 **局域网访问**：同一 Wi-Fi 下手机浏览器也能看

## 快速开始

需要：**Node.js 22+**（用到了内置 `node:sqlite`，仅存储本地消息缓存）。

```bash
# 1. 安装依赖（Electron，用于桌面窗口）
npm install

# 2. 启动桌面应用
npm start

# 或者只跑服务 + 浏览器
npm run server
# 然后打开 http://localhost:4322
```

使用流程：

1. 左侧「＋ 新建」，输入对方昵称；
2. 选中该联系人，点「📋 导入聊天记录」；
3. 去电脑聊天软件打开与 TA 的对话，右键「多选」→ 勾选一批 →「复制」；
4. 反复几次，点「⏹ 停止并导入」，首次会问「哪个是你自己」；
5. 看分析结果。

> 提示：电脑端记录不全时，先用手机聊天软件「聊天记录迁移」到电脑，再回来导入。

## 技术栈

- **后端**：Node.js 原生 `http` 模块（零框架依赖）
- **前端**：原生 HTML / CSS / JavaScript
- **桌面壳**：Electron
- **数据**：本地 JSON 文件（`data/` 目录）

#### ⚡ 优化与修复

**🤖 AI 链路**

- **模型下载源全部换成国内 ModelScope**（上一版用 `hf-mirror.com` / `huggingface.co`），并配了镜像兜底与 sha256 校验
- **断点续传增强**：分片下载 + 卡死检测（20 秒无数据即重连），弱网下不再整包重来
- **Vulkan 加速**：核显 / 独显都能吃到；没有可用 GPU 时自动回退 CPU
- **狗头军师、待办锐评改为真 AI 生成**（上一版是服务端精修模板 + 种子变体）
- AI 说出口的每个数字都会与真实统计核对，**编造的数字会被拦下**
- 移除了 Ollama 后端，安装包不再需要用户另行部署任何服务

**🔊 音效质量**

- 重新设计音色：短音效全部改用**整数倍泛音**，修掉不谐音带来的金属味
- 电平整体提高约一倍，并把提示音基频抬到笔记本人声喇叭能响的区间
- 短音效混响量下调（长音保留），点击音不再糊成一片
- 总线加限幅器，大音量下不会削波

**📊 数据与展示**

- 承诺追踪重做：从聊天记录里认出的承诺可自行增删改，并跟踪兑现情况
- 数字显示统一收口，修掉不同字体「老式数字」导致的高低不齐
- 液态玻璃质感增强，层级与景深更清楚

**⚡ 性能与稳定性**

- 修掉了「每次点击都会报一个错」与长列表滚动卡顿
- 移除启动脚本里的 `--disable-gpu`：实测帧间隔从 57ms 改善到 6ms
- AI 状态轮询加了内容缓存（内容没变就不重建 DOM），窗口最小化时暂停轮询
- 修掉停止抓取后轮询清不掉的僵尸请求
